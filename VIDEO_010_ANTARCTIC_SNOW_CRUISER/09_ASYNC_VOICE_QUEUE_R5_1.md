Personality=false исключает автоматическое переписывание текста; engine/seed/профиль зафиксированы. Нет изменения скорости, pitch-shift и искусственных пауз ради18–20 минут. Профиль без effects; normalization — при первичной генерации, без обработки принятого аудиомастера.

## Надёжность

- Межпроцессный lock запрещает второй worker той же очереди.
- Файл входа проверяется SHA256; каждый текст имеет свой hash и стабильный seed.
- Полученный generation_id записывается до продолжения; повторный запуск использует сохранённый ID.
- При неопределённом POST, ошибке генерации или неоднозначном совпадении автоматического перезапуска TTS нет.
- Завершённые WAV получают технические параметры и SHA256, но статус остаётся GENERATED_TECHNICAL_UNREVIEWED. ASR и слуховой PASS не подставляются.
- Для остановки новых отправок можно создать STOP_REQUESTED в папке очереди. Это не отменяет уже принятое Voicebox-задание.
- Очередь живёт пока запущены компьютер/процесс. После перезагрузки нужен повторный запуск того же worker с тем же состоянием; не новая очередь.
- Ограничение API: запрос history сlimit1000 возвращал500; рабочая проверка последних50 записей вернула200. Исправлен только наш клиент. Backend не патчился.

Текущий статус смотрится по QUEUE_STATE.json или tools/check_voice_queue.py по напоминанию владельца. Файлы очереди не означают, что озвучка уже готова.
