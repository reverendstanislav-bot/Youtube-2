### 2. Полноценная CTA-стратегия

Разработай органическую систему вовлечения для аудитории американского YouTube.

Требуются:

**SUBSCRIBE CTA**

- Один основной ненавязчивый устный призыв.
- Размещать после сильного сюжетного события.
- Подписка должна логически связываться с тематикой канала.
- Никакой просьбы подписаться в первые 60 секунд.
- Не прерывать кульминационные моменты.

**LIKE CTA**

- Один максимально короткий вариант.
- Сравнить устный призыв и визуальное напоминание без озвучки.
- Предпочесть решение с меньшим риском для удержания.
- Не вставлять шаблонное “smash that like button”.

**COMMENT CTA**

- Создать содержательный вопрос по теме Snow Cruiser.
- Вопрос должен допускать разные аргументированные ответы.
- Избегать банального “What do you think?”.
- Не подменять исторические факты искусственным спором.
- Подготовить отдельный закреплённый комментарий.

**END SCREEN**

- Сохранить утверждённый стандарт HIA: Subscribe + Previous Story.
- Финальная речь не должна мешать кликабельным элементам.
- Подготовить естественный переход к другому выпуску канала.
- Не выдумывать содержание Previous Story: проверить фактическое доступное видео.
