# HIA VIDEO010 — только бесплатные источники

Указание владельца: только бесплатные. Бюджет покупки архивов/лицензий — $0. Платные предложения LICENSE_RESEARCH_R1 исключены из дальнейшей работы. Оплат, заказов, регистраций аккаунтов и отправленных писем нет.

Добавлено: бесплатный PDF Army Observers’ Report of Operation Highjump (War Department, 1947), 424 сканированные страницы, 47 128 148 байт. Оригинал получен из коллекции U.S. National Library of Medicine на Internet Archive, SHA-256 проверен. Авторство официального ведомственного текста установлено по записи и изданию. Две прочитанные страницы отдельно растеризованы в 300 DPI и включены в MEDIA/DOCUMENTS по MANIFEST.csv. Это два фрагмента одного первичного отчёта, не два самостоятельных источника.

- Печатная347 / PDF359: свидетельство Dr. Siple о неофициальном вскрытии и разграблении Snow Cruiser в ходе Highjump.
- Печатная396 / PDF408: положение крыши машины вровень со снежной поверхностью в 1947-м.

На обложке есть исторические Restricted и Unclassified/declassification пометки; отмена ограничения видна на самом экземпляре. Этот отчёт нельзя переименовать в материал 1958 года. Он также не подтверждает популярный пересказ, будто в 1947-м машину достаточно было накачать и снова пустить в путь. Полный PDF оставлен исследовательским источником, не утверждённой медиатекой для всех его иллюстраций.

Дополнительно получен исследовательский фрагмент исходного MPEG NARA/FedFlix — 24.024 с выгрузки. Измерены 720×480, SAR8:9, отображение4:3, 29.97fps; запись каталога640×480 описывает отображаемую геометрию. Он не является HD и не является новой сценой: это то же событие, что в имеющихся копиях. Шесть кадров и сравнение с400×300 просмотрены. Гребёнка движения/мягкость/царапины остаются. Технический декод короткого MP4 PASS; права на частные компоненты и финальное качество HOLD. В MEDIA этот фрагмент не включён. Полный MPEG3.4GB не скачивался и не проверялся целиком. Не использовать неудачный первоначальный MKV.

NARA подтверждает передачу Universal copyright государству, но предупреждает о возможных сторонних компонентах отдельных сюжетов. Бесплатная загрузка не равна разрешению на публикацию. Проверенные1939записи Universal на IA не дали нужного сюжета: посторонние сюжеты не добавлены ради количества. Статья Hoinkes1962 доступна для чтения, но ясное разрешение для коммерческого воспроизведения фотографий не подтверждено — в MEDIA её нет.

Активный исходный набор: CURATED_EDIT_R2 + два документа из этого дополнения. Бесплатная качественная хроника с окончательно подтверждёнными правами, постройка/дорога и1958 по-прежнему HOLD. Финальный ролик/озвучка/генерация/монтаж/YouTube не запускались.
