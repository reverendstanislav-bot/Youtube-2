## Монтажный канон

Архив — основное изображение. Держать исходную геометрию;4:3 не растягивать до16:9 и не класть поверх постороннего тематического фона. Для каждой смены указан смысл; нет фиксированного правила «новая картинка каждые10сек».

По умолчанию неподвижный кадр и чистая склейка. Приближение допустимо только к названному предмету и в пределах реальных пикселей; ни общей тряски, ни дрейфа, ни постоянного зума. Не больше двух очень похожих видов подряд; повтор того же снимка должен быть осмысленным возвращением, а не псевдоновой сценой.

Графика — отдельные редактируемые слои: короткие пояснения механизма, локальные линии/подсветки, точные числа из ledger. Стиль и подход — по существующему CampCentury/HIA; не универсальные карточки, HUD, псевдоюридические документы или сгенерированные доказательства. Исходные главы с задачами:05R_VISUAL_REQUIREMENTS.md и competitor scene_application.

HISTORICAL SOURCE относится только к реальной текущей архивной картинке; DOCUMENT — к действительному документу. Современная NASA-съёмка2016 не становится RossIceShelf1940. Концептуальная схема не выдаётся за оригинальный чертёж или снятое событие. Диалоговых субтитров нет.
