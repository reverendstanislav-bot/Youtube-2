# Hidden Industrial America — channel system

**Format:** English-language, USA-focused, faceless, long-form documentary channel.

The channel is designed to scale across American industry, infrastructure, engineering, logistics, mining, factories, forgotten systems, and unusual technical projects. It must not visually or editorially depend on one episode theme.

## Core production chain

Research / evidence / source ledger → audience angle → packaging hypothesis → hooks → documentary architecture → retention outline → full script → fact check → final narration → VO → word-level transcript → exact timing → visual beat map → archive/source plan → download/licensing → missing-visual analysis → generation plan → complete prompt pack → generation-budget approval → assets → graphics/maps/charts → music/SFX plan → long-form edit → Shorts extraction map → captions → proof → review → critic audit → RC → exhaustive QC → native upload master.

## Channel-level rules

- Do not turn the channel into a repeated AI-slideshow template.
- Keep a shared brand language, but each story must have its own visual logic and evidence.
- Distinguish archive, document, map, technical drawing, reconstruction, generated explanatory visual, chart, and motion graphic when it matters.
- Preserve source/provenance information for third-party archive material.
- Generated/reconstructed images must fit the established documentary look and must not be passed off as archival evidence.
- Do not promote any build to FINAL, UPLOAD_MASTER, or APPROVED before explicit user approval.
- Store episode state in a canonical handoff/status file, not only in chat history.
- Do not use video generation unless the user explicitly lifts the channel-wide ban.
- Do not spend image-generation credits before the script, beat map, archive/download/generate/GFX classification, full prompt pack, exact generation count, and budget are reviewed.
- Shorts are designed while writing the long-form, with self-contained hooks/payoffs and extraction markers.

## Canonical caption rule

For new production, unless a later explicit approval changes it:
- base dialogue text: white #FFFFFF;
- current spoken word: orange #F28A3A;
- word-level timing;
- safe margins;
- one caption renderer/layer only;
- no blue dialogue words, opaque caption slabs, duplicated subtitles, or caption renderer in the YouTube end-screen zone.

The TC497 top-level canonical handoff and post-approval master QC are the precedent for this rule; stale intermediate V5/V13 review notes do not override them.
