# Hidden Industrial America — channel system

**Format:** English-language, USA-focused, faceless, long-form documentary channel.

The channel is designed to scale to many episodes across American industry, infrastructure, transport, engineering, logistics, forgotten systems, and unusual technical projects. It must not visually or editorially depend on one episode theme.

1. **Chicago** — first production episode; currently returned to repair because subtitles still drift.
2. **LeTourneau TC-497 Overland Train** — second production episode; FULL_V13 reached user-approved 1920x1080 publication master.

## Core production chain

Research / source package → script → VO → visual plan → archive + reconstruction → edit/compositing → subtitles → music/sound design → review build → human approval → native upload master → QC → publication.

## Channel-level rules

- Do not turn the channel into a repeated AI-slideshow template.
- Keep a shared brand language, but each story must have its own visual logic and evidence.
- Distinguish archive/document/concept/reconstruction when it matters.
- Preserve source/provenance information for third-party archive material.
- Generated/reconstructed images must fit the established documentary look and must not be passed off as archival evidence.
- Do not promote any build to `FINAL`, `UPLOAD_MASTER`, or `APPROVED` before explicit user approval.
- Store episode state in a canonical handoff/status file, not only in chat history.
