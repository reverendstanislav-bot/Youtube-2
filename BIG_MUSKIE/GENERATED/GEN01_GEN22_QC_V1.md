## Root cause

The reference-photo approach was not strong enough to lock the 4250-W's defining lower architecture.
GPT Image repeatedly generalized Big Muskie into a conventional tracked/crawler dragline.

Future replacements must explicitly lock:
1. **large circular tub / base**;
2. **walking shoes / stepping architecture**;
3. **no crawler tracks, no wheels, no rail running gear**;
4. correct Big Muskie boom/house/tub proportions;
5. only the requested cycle/action phase;
6. bottom 12–15% subtitle-safe band.

For GEN13/GEN14 in particular, use the engineering source/patent geometry as an additional reference requirement rather than only exterior photographs.
