# BIG MUSKIE — SOURCE FILES

No Episode 3 production media has been approved or downloaded into the canonical source package yet.

Future source intake must record:
- filename;
- source URL;
- source/publisher/archive;
- author/creator;
- date;
- license / public-domain / CC status / permission;
- what the source proves or depicts;
- SHA-256 after download;
- approved / rejected status.

Do not treat a search-result image, Google image, social post, or unlabeled scan as cleared production media.
