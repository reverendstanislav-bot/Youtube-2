## D05 — 1977 Bureau of Mines / Penn State study

This physical PDF materially changes the remap because it contains production-usable primary-source visuals:

- page 8: mine description identifying the north-pit BE4250-W operation;
- page 9: 1976 production context and overburden/bench description;
- Figure 1: generalized overburden section above the Meigs Creek coal seam;
- Figure 2: **Pit Layout for BE4250-W Dragline Operation** — plan and cross-section;
- Figure 3: **Aerial Photograph of the Mining Area**, explicitly marking BE4250 DL, active pit, haulback areas and blast-hole drilling;
- Figure 4: **Flow Diagram of the Materials Handling System**, separating the stripping-dragline overburden system from coal removal;
- page 24 / Table 5: availability discussion;
- Table 8: actual-month 75.25-second cycle, 35% BE4250-W availability and 1,949,200 yd³/month dragline overburden removal.

These pages replace several previously planned generic GFX/reconstruction beats.

## D03 / D04

Physical patent PDFs are retained for source-grounded hoist and stepping-mechanism explanation. They do not justify calling a drawing an exact Big Muskie blueprint.

## D06

Physical EPA Title IV source note supports the 1990 amendments / 1995 Phase I timeline. It does not support a claim that EPA directly shut Big Muskie in January 1991.

## Audit conclusion

The V2 clean archive is strong on:
- machine scale / identity;
- current bucket legacy;
- mine layout and overburden geometry;
- real 1977 operating-system diagrams/data;
- land-system and reclamation context.

It is weak on:
- onsite assembly;
- human-scale assembly;
- precise operating-cycle action phases;
- the actual walking step;
- crew/maintenance workplace scenes;
- physical dismantling in 1999.

Those weaknesses define the reconstruction list rather than a target number of AI images.
