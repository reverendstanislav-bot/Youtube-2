# Chicago project history — condensed

This file preserves the useful project history that previously existed only across chats.

## Package / archive phase

Two Chicago CODEX_READY archives existed:
- `Hidden_Industrial_America_Chicago_CODEX_READY_v7(5).rar`
- `Hidden_Industrial_America_Chicago_CODEX_READY_v7(6).rar`

The goal was a single lossless ZIP/archive with no duplicated files and no missing information.

A separate guide existed:
- `Hidden_Industrial_America_Quick_Usage_Guide_RU(1).pdf`

The user requested that the guide be included as item 11 in the combined package.

## Branding phase

Channel branding and thumbnail work were explicitly separated from the first episode concept. The user rejected branding that was too tied to the first Chicago video's imagery/theme because the channel is intended to contain hundreds of future videos across different industries.

Therefore:
- Chicago visuals are episode-specific;
- channel identity must remain scalable and category-agnostic.

## Export / delivery phase

A large Chicago MP4 was difficult to deliver as one file. Earlier delivery attempts used split files, including a four-part form named like:
- `HIA_CHICAGO_FINAL_UPLOAD.mp4.part00`
- `...part01`
- `...part02`
- `...part03`

Later Dropbox storage contains a different 14-part split:
- `HIA_DBX_00.part` … `HIA_DBX_13.part`

## Last known defect

After delivery/export attempts, the user checked the video and reported that subtitles still drifted. Therefore the old upload candidate was never truly closed/approved.

This is the correct restart point: recover the real media, repair subtitle timing, review, then finalize.
