# SATSOP — STAGE 6 V3 DIRECTORIAL PREFLIGHT

Updated: 2026-09-25

## Verdict

**PASS FOR REFERENCE ACQUISITION AND TARGETED VALIDATION. NO GENERATION AUTHORIZED.**

V3 removes the main causes of the weak V1 and V2 test results before any further spend. It does not predict or claim an achieved image pass rate; that can only be measured after the gated validation set is generated and reviewed.

## What changed

- **13 accepted images remain locked.** They are excluded from all future generation jobs.
- **16 factual map, chronology, technical and quantitative positions are editor-built GFX.** Their prompts are deterministic build briefs, cost zero image credits, and forbid generated geography, engineering, numbers and relationships.
- **10 site-specific positions require real reference media IDs.** They cannot be submitted as text-only jobs.
- **29 interpretive reconstructions remain eligible for controlled text generation.** Each uses one clear subject, one composition, blank document surfaces and no factual diagram or readable model text.
- Every one of the **55 pending positions has an individual V3 brief** and an explicit execution gate.
- All **12 non-passing positions from the V2 test** received direct compositional corrections.

## Expected directorial improvement

The previous tests failed mainly because the image model was asked to invent exact Satsop architecture, geography, engineering diagrams, chronology and finance graphics. V3 removes those tasks from unconstrained generation. The remaining generated scenes have narrower frames, fewer competing subjects, restrained lighting, protected caption space and explicit exclusions.

This design should reduce failures caused by:

- invented reactor domes, cooling towers and site layouts;
- generic repeated nuclear-construction imagery;
- illegible in-image text and fake documents;
- decorative diagrams that misstate factual relationships;
- overloaded frames with several simultaneous ideas;
- modern or cinematic imagery presented as historical evidence.
